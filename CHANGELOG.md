# Changelog

## [1.0.0] - 2026-09-07

### Added
- Responsive URL safety checker UI.
- URL normalization and validation.
- Local phishing-risk heuristics.
- Google Safe Browsing integration.
- VirusTotal integration.
- Optional URLScan configuration.
- Risk scoring and verdicts.
- MySQL schema.
- Security and contribution documentation.

### Security
- API keys remain server-side.
- The application does not directly fetch arbitrary user URLs from the
  application server.
